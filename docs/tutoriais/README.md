# Trilha de aprendizado

Cada capítulo ensina uma tarefa efetivamente entregue e explica como e por que cada passo foi realizado. O [fluxo de trabalho](../fluxo-de-trabalho.md) define o critério de conclusão e os modelos.

1. [PROC-01 — Organizar uma equipe de agentes e exigir tutoriais por tarefa](PROC-01.md).
2. [1.1 — Construir a base JavaScript com React, Vite e Express](define-puzzle-platform-mvp/1.1.md).
3. [PROC-02 — Analisar referências e definir uma direção UI/UX](PROC-02.md).
4. [1.2 — Encaminhar a API e entregar o build com Express](define-puzzle-platform-mvp/1.2.md).
5. [1.3 — Validar configuração antes de iniciar o servidor](define-puzzle-platform-mvp/1.3.md).
6. [PROC-03 — Escrever e revisar código para quem está aprendendo](PROC-03.md).

O capítulo 1.1 ensina o bootstrap; 1.2 acrescenta proxy, saúde e entrega do build; 1.3 valida o ambiente e acrescenta testes e o comando de migração explicitamente pendente da 2.1. Siga 1.3 e o README vigente para configurar a base; 1.1 e 1.2 preservam seus contextos históricos. Os próximos capítulos serão acrescentados conforme as [tarefas do MVP](../../openspec/changes/define-puzzle-platform-mvp/tasks.md) forem entregues, seguindo base local, persistência, autenticação, APIs, interfaces e entrega. PROC-01 também preserva seu ponto inicial histórico.

PROC-02 acrescenta o designer UI/UX e explica o guia e a folha visual documentais. Para tarefas de interface, siga esse capítulo e o [fluxo atual](../fluxo-de-trabalho.md); os capítulos anteriores permanecem como registros históricos de seus pontos iniciais. Definir o estilo não significa que ele já esteja aplicado à aplicação.

PROC-03 ensina como aplicar e revisar o [critério de simplicidade vigente](../fluxo-de-trabalho.md#código-simples-para-quem-está-aprendendo). Use esse critério nas próximas tarefas. PROC-01 e PROC-02 documentam o processo nas versões indicadas em seus capítulos.
