# Trilha de aprendizado

Cada capítulo ensina uma tarefa efetivamente entregue e explica como e por que cada passo foi realizado. O [fluxo de trabalho](../fluxo-de-trabalho.md) define o critério de conclusão e os modelos.

1. [PROC-01 — Organizar uma equipe de agentes e exigir tutoriais por tarefa](PROC-01.md).

Os capítulos de implementação serão acrescentados aqui conforme as [tarefas do MVP](../../openspec/changes/define-puzzle-platform-mvp/tasks.md) forem entregues. Os capítulos da base local precedem os de persistência, autenticação, APIs, interfaces e entrega. Não há capítulos de funcionalidades implementadas neste momento.
