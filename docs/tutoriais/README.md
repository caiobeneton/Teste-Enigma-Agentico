# Trilha de aprendizado

Cada capítulo ensina uma tarefa efetivamente entregue e explica como e por que cada passo foi realizado. O [fluxo de trabalho](../fluxo-de-trabalho.md) define o critério de conclusão e os modelos.

1. [PROC-01 — Organizar uma equipe de agentes e exigir tutoriais por tarefa](PROC-01.md).
2. [1.1 — Construir a base JavaScript com React, Vite e Express](define-puzzle-platform-mvp/1.1.md).

O primeiro capítulo de implementação ensina o bootstrap: frontend mínimo e fábrica Express importável. Os próximos capítulos serão acrescentados conforme as [tarefas do MVP](../../openspec/changes/define-puzzle-platform-mvp/tasks.md) forem entregues, seguindo base local, persistência, autenticação, APIs, interfaces e entrega. O capítulo PROC-01 preserva seu ponto inicial histórico; siga o capítulo 1.1 para o procedimento vigente de instalação e execução da base.
