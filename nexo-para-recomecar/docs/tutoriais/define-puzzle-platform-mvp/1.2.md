# 1.2. Proxy e servidor Express

## O que foi entregue

O Vite encaminha as requisições de `/api` ao Express em desenvolvimento. A rota `/api/health` informa se o servidor está ativo. Rotas desconhecidas da API retornam um erro 404 em JSON. Em produção, o Express entrega também os arquivos compilados do frontend.
