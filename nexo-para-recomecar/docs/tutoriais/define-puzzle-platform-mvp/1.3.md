# 1.3. Configuração e testes locais

## O que foi entregue

O servidor valida as variáveis de ambiente e o diretório de dados antes de aceitar requisições. O Git ignora os dados locais. Os testes cobrem a configuração e as rotas HTTP. O comando `npm run migrate` informa que as migrações SQLite dependem da tarefa 2.1.

## Arquivos

- [Validação da configuração](../../../api/src/config.js) e [entrada do servidor](../../../api/src/server.js).
- [Testes](../../../api/test/config.test.js), [comando de migração](../../../api/src/migrate.js) e [regras do Git](../../../.gitignore).
- [Registro da tarefa 1.3](../../registros/define-puzzle-platform-mvp/1.3.md).

## Como conferir

Após [instalar as dependências](../../../README.md#executar-a-base-local), execute `npm test` na raiz do repositório. Os testes devem passar.
