# Nexo. Planejamento para um novo repositório

O Nexo é uma plataforma comunitária de enigmas textuais. Uma conta permite criar enigmas e jogar. Cada jogador avança individualmente pelas etapas de um enigma.

## Por onde começar

1. Leia a [proposta do MVP](openspec/changes/define-puzzle-platform-mvp/proposal.md) para conhecer o escopo aprovado e as decisões em aberto.
2. Consulte as [especificações](openspec/changes/define-puzzle-platform-mvp/specs/) para conferir regras e cenários de uso.
3. Leia o [design técnico](openspec/changes/define-puzzle-platform-mvp/design.md) e o [guia visual](docs/design/estilo-interface.md) antes de definir os contratos e as telas.
4. Use a [fila OpenSpec](openspec/changes/define-puzzle-platform-mvp/tasks.md) para organizar a implementação. As 41 tarefas começam pendentes nesta cópia.
5. Consulte o [fluxo de trabalho](docs/fluxo-de-trabalho.md) e as [instruções para agentes](AGENTS.md) para registrar e verificar as entregas.
6. Confira o [relatório EGM](docs/revisoes/PROC-06/consolidated_review_report.md) antes de iniciar as tarefas técnicas que ele indica.

## Executar a base local

Implemente primeiro as tarefas 1.1 a 1.3. Os [tutoriais existentes](docs/tutoriais/README.md) registram como a base foi criada no repositório de origem, na versão `4e4fe17`. Os caminhos de código, comandos de execução e commits citados nesses tutoriais são referências daquela implementação. Nesta cópia, eles passam a se aplicar conforme vocês recriarem a base.

Ao concluir cada tarefa refeita, atualize seu registro e seu tutorial com as evidências do novo repositório. O primeiro commit da cópia pode guardar a versão de referência dos documentos.
